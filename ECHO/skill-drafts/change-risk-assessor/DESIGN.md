# Change Risk Assessor 设计说明

## 原型
逐个审阅候选变更，识别有因果机制的副作用，给出影响对象、可能性/影响/置信度、预防缓解、可观测信号、回滚触发器和残余风险。风险未知就标未知，不生成假概率。

## 优化重点
- 不把模板式风险大清单当分析；只保留与变更有关且解释机制的风险。
- 将固有风险与控制后的残余风险分开。
- 风险项必须配可观察信号和可执行的回滚门槛。
- 明确 Skill 只提供评估，不执行上线、停机或回滚。

## GitHub 借鉴
- [Unleash](https://github.com/Unleash/unleash)：开源 Feature Management 支持渐进发布、kill switch 等机制，可借鉴“分阶段暴露和快速关闭”的风险控制思路；部署它需要工程集成，Skill 本身不能提供这些控制。
- [GrowthBook](https://github.com/growthbook/growthbook)：实验与 feature flag 的结合可帮助将高不确定改动放入可测实验；不能把实验平台当成安全评估或隐私审查的替代品。

## 未来改进
加入产品领域风险词典和历史事故样例；按行业/数据敏感性配置审查门槛；连接发布监控数据；对风险预测与实际事故做事后校准；审计建议是否有可执行回滚条件。
