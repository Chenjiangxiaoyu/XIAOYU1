# Improvement Planner 设计说明

## 原型
从 evidence-backed finding 生成多个备选改进路径，标明用户、问题、证据、假设、成本依据、影响和不确定性；输出候选方案而非把模型意见伪装成路线图。之后由风险评估和成功标准 Skills 补齐。

## 优化重点
- 把用户表达转成问题陈述，再讨论方案，避免照单全收或直接跳到“加功能”。
- 同时保留“不改/补研究/低风险试验/较大方案”选项，避免单一建议。
- 排序理由透明；无真实成本或业务目标时不伪造 ROI 和精确分数。
- 增加证据 ID、假设、依赖和待决问题字段，让产品经理能追问和评审。

## GitHub 借鉴
- [GrowthBook Agent Skills](https://github.com/growthbook/skills)：其实验设计技能结构强调假设、变体、主指标和护栏指标；借鉴结构化方案和交接，但本 Skill 不调用 GrowthBook，也不假定用户已安装实验平台。
- [GrowthBook](https://github.com/growthbook/growthbook)：可作为未来进行实验验证的开源平台；不是产品建议排序算法，也不能替代反馈证据和业务优先级判断。

## 未来改进
接入产品目标、成本估算、技术依赖与路线图；从历史改进结果学习估算偏差；支持按行业/产品阶段配置排序权重；与成功标准输出组成方案评审卡。需用真实产品经理评审集验证可操作性与非空泛率。
